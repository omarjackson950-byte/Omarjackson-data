How it works

Memory as algebra, not a database

Traditional AI memory uses vector databases, embeddings APIs, and network calls. Nuggets uses circular convolution — 1ms recall, zero external dependencies, deterministic by design.

STEP 01

Bind a memory

Key + value are encoded into a 512-dim vector via circular convolution. The vector is stored locally as JSON — no database required.

STEP 02

Probe for recall

Querying uses circular correlation — the mathematical inverse of binding. Sub-millisecond, deterministic, no neural network inference.

STEP 03

Verify with anchors

Every memory state produces an 8-byte fingerprint. Agents compare anchors across turns to detect drift and guarantee consistency.

STEP 04

Sync to cloud (Pro)

Push your local store to the cloud for multi-device or team access. Merge is conflict-aware — newer writes win, anchors reconcile.

nuggets-memory-pro
# Store a memory
→ memory_remember { key: "sprint_goal", value: "Ship auth by Friday", priority: 2 }
{ ok: true, anchor: "a1b2c3d4e5f6g7h8", slots: 1 }

# Recall it next session (agent has zero context)
→ memory_recall { key: "sprint_goal" }
{ label: "sprint_goal", similarity: 0.94, priority: 2 }

# Pro: verify state didn't drift between agent turns
→ memory_anchor { compareWith: "a1b2c3d4e5f6g7h8" }
{ current: "a1b2c3d4e5f6g7h8", match: true, driftDetected: false }
